Program outline

Six weeks, twelve live classes. We pick one business problem and solve it with an Agentic AI solution: the first three weeks build the pipeline layer by layer, the last three take it to production.

  1. Week 1

    Agentic AI Fundamentals

    What agents are and where they fit in the enterprise. We set up the business problem we solve through the course and start with the prompt layer: designing the agent's prompts.

    • Class 1: Introduction to Agentic AI
      • What an agent is: an LLM, tools and a decision loop; agents versus workflows and chatbots
      • The enterprise landscape and where agents fit
      • The business problem we solve through the course
    • Class 2: Prompt Engineering and Designing Agents
      • The prompt layer: system prompts, structured outputs, few-shot examples
      • Designing the agent's decision loop in LangChain and LangGraph
      • Programmatic prompts with DSPy

    You build: The first version of the agent: a prompt-driven assistant for the business problem.

    Tools: LangChain, Langgraph, OpenAI, DSPy

  2. Week 2

    Retrieval Augmented Generation

    The RAG layer: embeddings and retrieval that ground the agent in enterprise knowledge, and how to design the retrieval pipeline.

    • Class 3: Embeddings and RAG
      • Embeddings with Sentence Transformers, and similarity search
      • Chunking and indexing documents
      • Re-ranking with cross encoders
      • The retrieve-then-generate loop
    • Class 4: RAG Design
      • Chunking strategies and metadata
      • Query rewriting and re-ranking
      • Grounding answers and measuring retrieval quality

    You build: The RAG layer: the agent answers from enterprise documents.

    Tools: Sentence Transformers, Cross Encoders, Chroma DB

  3. Week 3

    Tool Engineering & Memory

    The tool-calling and memory layers: external integrations, persistent memory and the Model Context Protocol.

    • Class 5: Tool Engineering
      • Tool schemas and function calling
      • Designing tools agents can call reliably: errors, retries, timeouts
      • Tool-call loops in LangGraph
    • Class 6: Memory in Agents, Model Context Protocol
      • Short-term and long-term memory with LangMem and Redis
      • What agents should remember, and for how long
      • Exposing tools and data through MCP

    You build: Tools and memory added to the agent. This completes the build; the remaining weeks productionize it.

    Tools: MCP, LangMem, Redis

  4. Week 4

    Evaluating Agentic AI Systems

    Why evaluating LLM applications is hard: traditional ML and software are deterministic with objective metrics, while LLM systems are subjective and non-deterministic. We build a failure mode taxonomy, compute its statistics, update the pipeline to mitigate the failures, and use this to compare two agentic solutions objectively.

    • Class 7: Evaluating your Agent
      • Why LLM evals differ from ML metrics: subjective, non-deterministic outputs
      • Component-wise evaluation: prompt evals, RAG evals, tool-calling evals
      • Building an evaluation dataset for each component
    • Class 8: Error Analysis, LLM as Judge
      • Determining a failure mode taxonomy and computing its statistics
      • Updating the pipeline to mitigate the failure modes
      • Designing an LLM judge and validating it against human labels

    You build: An evaluation harness for the pipeline, and a pipeline updated to fix its top failure modes.

  5. Week 5

    Agentic RAG & Inference Optimization

    Agentic RAG and inference optimization: designing for latency-sensitive versus accuracy-sensitive pipelines, and when to use online judges or offline judges to improve your pipeline.

    • Class 9: Agentic RAG + Finetuning
      • Agentic RAG: the agent decides when and what to retrieve
      • Online judges versus offline judges
    • Class 10: Inference Optimization
      • Latency-sensitive versus accuracy-sensitive pipelines
      • Serving with vLLM: batching, caching, quantization
      • Choosing a model per pipeline stage

    You build: A latency-tuned version of the pipeline with agentic retrieval.

    Tools: Langgraph, vLLM

  6. Week 6

    Production & Multi-Agent Systems

    Observability, guardrails, multi-agent systems and deployment: what it takes to run the pipeline in production.

    • Class 11: Observability and Guardrails
      • Tracing and monitoring agents in production
      • Input and output guardrails
      • Cost and latency monitoring
    • Class 12: Case Study: Inventory Planner; A2A Protocol, Deployment, Change Management
      • Case study: an inventory planner built with the course's patterns
      • Multi-agent systems and the A2A protocol
      • Deploying with Docker on Azure Cloud, and rolling out to users

    You build: The pipeline deployed, observed and guarded in production.

    Tools: Opik, Docker, Azure Cloud, A2A Protocol
