Setup Instructions

If you are new to Python, start with Google Colab.
If experienced with Python, start with local.

Step 1 Access Colab and install packages ▼

Visit Google Colab and sign in with your Google account.

Click File → New notebook in Drive

In the first code cell, run this command to install the required packages (the ! prefix is required):

!pip install groq python-dotenv gradio
Step 2 Get a Groq API key ▼

Visit the Groq website. Go to Developers → Free API Key.

Sign in with your email.

Click Create API Key.

Give it a name (e.g. GenAICourse) and copy the key. Never share this with anyone.

Back in your Colab notebook, click the key icon in the left sidebar and then Add new secret.

Set NAME to GROQ_API_KEY and paste the key as the VALUE. Enable Notebook access.

Verify the setup by running this in a new cell:

from groq import Groq
from google.colab import userdata

groq_api_key = userdata.get('GROQ_API_KEY')
client = Groq(api_key=groq_api_key)
response = client.chat.completions.create(
    model="llama3-8b-8192",
    messages=[{"role": "user", "content": "Say hello world"}]
)
print(response.choices[0].message.content)
You should see a response from the model if your key is set up correctly.
Step 3 Build your first chatbot ▼

Paste this code into a new cell and run it:

import gradio as gr
from groq import Groq
from google.colab import userdata

groq_api_key = userdata.get('GROQ_API_KEY')
MODEL = "llama-3.3-70b-versatile"
client = Groq(api_key=groq_api_key)
system_message = "You are a helpful assistant"

def chat(message, history):
    history = [{"role": msg["role"], "content": msg["content"]} for msg in history]
    messages = (
        [{"role": "system", "content": system_message}]
        + history
        + [{"role": "user", "content": message}]
    )
    stream = client.chat.completions.create(model=MODEL, messages=messages, stream=True)
    response = ""
    for chunk in stream:
        response += chunk.choices[0].delta.content or ""
        yield response

gr.ChatInterface(fn=chat, type="messages").launch()

Colab will print a public URL and may embed the chatbot directly in the notebook.

Step 1 Install packages ▼

In your activated Python environment, run:

pip install groq python-dotenv gradio
Step 2 Get and configure a Groq API key ▼

Visit Groq's platform, create an account, and generate an API key.

Create a file named .env in your project folder and add:

GROQ_API_KEY="your-api-key-here"
Never commit your .env file to a public repository.

Verify your key works by creating verify_groq.py:

from dotenv import load_dotenv
from groq import Groq

load_dotenv()
client = Groq()
response = client.chat.completions.create(
    model="llama3-8b-8192",
    messages=[{"role": "user", "content": "Say hello world"}]
)
print(response.choices[0].message.content)

Run it: python verify_groq.py

Step 4 Build your first chatbot ▼

Create a file called app_chatbot.py:

from dotenv import load_dotenv
import gradio as gr
from groq import Groq

load_dotenv()
MODEL = "llama-3.3-70b-versatile"
client = Groq()
system_message = "You are a helpful assistant"

def chat(message, history):
    history = [{"role": msg["role"], "content": msg["content"]} for msg in history]
    messages = (
        [{"role": "system", "content": system_message}]
        + history
        + [{"role": "user", "content": message}]
    )
    stream = client.chat.completions.create(model=MODEL, messages=messages, stream=True)
    response = ""
    for chunk in stream:
        response += chunk.choices[0].delta.content or ""
        yield response

gr.ChatInterface(fn=chat, type="messages").launch()

Run it:

python app_chatbot.py

Open the local URL printed in your terminal (e.g. http://127.0.0.1:7860) in your browser.
