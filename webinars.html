What we'll cover

  1. How an agent differs from a chatbotWhat makes an LLM application an agent rather than a question-answer loop.
  2. The agent loopThink, pick a tool, act, observe, and repeat until the task is done.
  3. Giving the agent tools and memoryLetting it call real functions and remember what it has already done.
  4. Common pitfalls and how to debug themWhere first agents go wrong, and how to find out why.

No prior agent experience needed. Basic Python knowledge helps.
